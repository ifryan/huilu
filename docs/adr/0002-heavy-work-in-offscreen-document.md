# ADR 0002：录制与耗时任务放在离屏文档中执行

- 状态：已接受（2026-09-24）

## 背景

MV3 的后台 Service Worker 空闲约 30 秒即可能被浏览器回收，不适合长时间录制或等待转写 / 大模型接口返回。

## 决定

- 后台只负责调度与消息转发
- 采集、混音、MediaRecorder 录制、分片落盘，以及会后处理管线（转写 → 纪要 → 关键帧 → 写入数据文件夹）都在离屏文档（`chrome.offscreen`）中执行
- 任务状态持久化在 IndexedDB，被中断后从上次完成的步骤继续

## 影响

- 离屏文档的生命周期需要由后台管理（按需创建、任务结束后关闭）
- 写入用户数据文件夹若因授权失效失败，任务停在「待写入」状态，待用户在插件网页中重新授权后补写
