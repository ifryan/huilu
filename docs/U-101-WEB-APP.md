# U-101 网页版验收说明

## 交付与运行

基于 `origin/main@4d88f5c`，分支 `feat/U-101-web-app`。新增 Vite 静态宿主与 `packages/app-shell`；插件使用原路径 facade 复用共享代码，平台差异默认关闭。没有创建 PR、合并或部署。

```bash
pnpm install
pnpm check
pnpm build
pnpm --filter @huilu/web preview
```

网页产物在 `apps/web/dist/`，插件产物仍在 `apps/extension/.output/chrome-mv3/`。网页可发布到 HTTPS 静态主机或本机 preview；相对资源与 hash 路由支持子路径。没有服务器运行时、遥测或托管代理。

## 已知限制

- 支持文件夹的浏览器尚未选择 / 重新授权时，最终任务停在待写入；中间结果与录制在 OPFS 中保留。
- 网页、插件、不同站点 Origin 的浏览器数据互不相通。数据文件夹可作为互通源；仅浏览器存储模式需及时下载备份。
- 处理依赖打开的页面；关闭 / 刷新会中断，需再次打开恢复。后台标签页可能被系统节流 / 回收。没有 PWA 应用壳离线缓存。
- CORS 的默认端点测量具有时间 / Origin / 路径局限；`/models` 连接测试通过不代表转写上传或生成通过。脚本不能严格区分 CORS / DNS / TLS，提示保留这种不确定性。
- 静态构建包含媒体处理与 AI SDK，当前有大 chunk 提醒；不影响纯静态交付，可在后续按媒体 / 路由进一步拆包。
- 网页设置 / 就绪订阅 / mount 的宿主装配保留约 250 行相似代码；主要业务页面、组件、会议库、处理视图已共享，未复制维护两份页面。
